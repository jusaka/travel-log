# 🛫 旅途纵横 (Travel Log)

一款**模仿航旅纵横**的单文件PWA应用，记录你的飞行和高铁旅程，可视化你的旅途足迹。

## ✨ 核心功能

### 📍 足迹地图
- Canvas绘制中国地图，支持缩放、拖拽、双指手势
- 金色飞行弧线 + 绿色高铁虚线
- 城市标签自动显示，大小反映到访次数
- 点击城市tooltip跳转到该城市行程列表

### ✈️ 行程管理
- 飞行/高铁双类型支持
- **登机牌风格详情页**：大字IATA代码，航线时长，距离统计
- **返程快捷功能**：保存后一键添加反向行程
- 长按行程卡片：编辑/复制/删除快捷菜单（带震动反馈）
- 搜索/筛选/排序 + 关键词高亮

### 📊 统计分析
- 总里程、分类里程、旅途时间
- 饼图：飞行/高铁占比
- 历史里程曲线图
- 趣味对比：绕地球圈数、到月球进度、马拉松等效
- **🏆 旅行纪录**：
  - 🔥 最长连续出行
  - 📏 最远单程
  - 📍 最近单程
  - 📅 最忙月份
- Top 10 常去城市（条形图）
- Top 5 常飞航司
- 月度出行柱状图

### 📅 年度报告
- GitHub风格贡献热力图
- 年度总览卡片
- 年份切换

### 🎨 双主题
- 🌙 深色模式（默认）
- ☀️ 浅色模式
- 地图Canvas自适应主题颜色

### 💾 数据管理
- JSON格式导出/导入
- **CSV格式支持**：
  - 导出为Excel兼容CSV
  - 导入支持中英文表头自动映射
  - 自动查询坐标（支持IATA机场代码和车站名）
- 本地localStorage持久化

### ⚡ 用户体验
- 键盘快捷键：`N`新建、`1-4`切换标签、`Esc`关闭
- 响应式设计：414px、375px断点优化
- 入场动画：卡片slideIn渐入
- 触摸优化：44px最小点击区域、长按500ms
- PWA支持：可安装到主屏幕、离线可用

## 🗂️ 数据库

### 机场
- 涵盖70+国内主要机场
- IATA三字码 + 精确经纬度

### 车站
- 30+高铁车站
- 主要枢纽站点

### 航司
- 20+航空公司
- 自动识别航班号前缀

## 📱 技术栈

- **架构**：单文件PWA（无构建工具）
- **前端**：原生JS + Canvas绘图
- **数据**：localStorage
- **地图**：GeoJSON + Canvas渲染
- **离线**：Service Worker
- **代码量**：2700+行（index.html 334行 + JS 1968行 + CSS 398行）

## 🚀 部署

### 本地测试
```bash
# 需要HTTP服务器（Service Worker要求）
python3 -m http.server 8765
# 或
npx serve
```

### Cloudflare Pages
```bash
# 直接部署，无需构建
wrangler pages deploy . --project-name=travel-log
```

### GitHub Pages
```bash
# 开启Pages，选择main分支
# 访问 https://<username>.github.io/travel-log/
```
